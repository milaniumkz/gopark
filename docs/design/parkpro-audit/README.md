## Дизайн-правила для переноса

- Светлый фон `#f6f8fc`, белые панели, радиус 12-16 px для крупных контейнеров, 8-12 px для контролов.
- Левое меню широкое, с группами разделов и крупными читаемыми пунктами.
- Основной экран занимает всю доступную ширину без внешнего горизонтального скролла.
- Верх страницы: компактный заголовок, дата/период, основные действия справа.
- Метрики: небольшие карточки, крупное число, короткая подпись, цветной статус/иконка.
- Таблицы: фиксированные колонки, компактные строки, важные данные без переноса по буквам.
- Фильтры: чипы и селекты в одну рабочую панель, активное состояние синим.
- Цвета статусов: зеленый активно/оплачено, красный долг/ошибка, оранжевый внимание, синий фильтр/действие, серый нет данных.

Исходные данные аудита находятся в `audit.json`.
